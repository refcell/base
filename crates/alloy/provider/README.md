OP Stack provider extensions for Base, including Engine API RPC methods.

## Overview

This crate provides provider extensions for interfacing with OP Stack execution clients:

- **Engine API**: Extended Engine API methods for OP Stack compatibility

## Usage

Add the dependency to your `Cargo.toml`:

```toml
[dependencies]
base-alloy-provider = { git = "https://github.com/base/base" }
```
