# base-protocol

Core protocol types for the Base L2 network.

Ported from [`kona-protocol`](https://github.com/ethereum-optimism/kona).

These include types, constants, and methods for derivation as well as batch-submission.

## Features

- `std` - Standard library support
- `serde` - Serialization/deserialization support
- `arbitrary` - Property-based testing support
- `test-utils` - Testing utilities

## Usage

```toml
[dependencies]
base-protocol = { workspace = true }
```
