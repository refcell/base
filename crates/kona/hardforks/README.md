# base-hardforks

Consensus layer hardfork types for the OP Stack including network upgrade transactions.

Ported from [`kona-hardforks`](https://github.com/ethereum-optimism/kona).

## Features

- `std` - Standard library support
- `k256` - Cryptographic signature support
- `kzg` - KZG support

## Usage

```toml
[dependencies]
base-hardforks = { workspace = true }
```
